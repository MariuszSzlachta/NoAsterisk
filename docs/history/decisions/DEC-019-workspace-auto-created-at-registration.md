## Preserved decision record

**Date:** 2026-06-22

**Decision:** User registration = automatic creation of workspace + permission (full access). 1 user = 1 workspace for MVP.

**Justification:**
- Zero friction at signup — user can immediately import
- Workspace invite (sharing) is a separate flow for the future
- Eliminates the state of "user without workspace" (invalid state impossible)
